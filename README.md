# Zen pinned-bookmarks mirror spike

This repository is a personal development mirror of `zen-browser/desktop` used to test a bidirectional mapping between Zen pinned tabs/folders and Firefox bookmarks.

The `dev` branch is bootstrapped from Zen's upstream `dev` branch. Experimental work belongs on `spike/pinned-bookmarks-mirror`.

> Use a disposable Zen profile and back up bookmarks before testing bidirectional synchronization or remote deletions.
